# Bob M11 Wiring Extraction

## Motivation

Bob's current CLI handlers mix argument parsing, environment/config resolution,
application wiring, subprocess setup, and command execution. This makes it easy
for a value to be produced in one place but not consumed in another, especially
across Vroom, YOLO, sandbox, and cost-tracking boundaries.

The goal of M11 is to extract typed config and app wiring helpers while
preserving the public CLI behavior. This is an architectural consolidation
pass, not a feature expansion.

## Features

### F1: Run config extraction
- task_type: library
- verifier: python_pytest
- success_criteria:
  - CLI args and environment variables map into typed run/sandbox/YOLO config objects.
  - `bob run` preserves the existing CLI surface and behavior.
  - Existing CLI, wiring, YOLO, sandbox, and E2E tests still pass.
  - New focused tests prove `--project`, `--inputs`, `--sandbox`, `--max-cost`, `--yolo`, `--no-gate`, and `--otel-endpoint` reach the downstream coordinator wiring.
  - The command handler in `claude_orchestrator/bob/cli.py` is thinner and does not manually assemble all downstream objects inline.
- description: Introduce a small config/wiring module for `bob run` that resolves CLI args and environment values into typed config objects, then builds the existing Coordinator with no behavior change.

### F2: Vroom config extraction
- task_type: library
- verifier: python_pytest
- success_criteria:
  - Vroom daemon and `bob vroom now` construct from typed Vroom config rather than ad hoc env reads in each command handler.
  - YOLO subprocess env reconstruction remains covered by tests and preserves sandbox tier, max cost, severity threshold, and max inconclusive bounds.
  - Vroom auditor selection, sandbox executor selection, triage gate setup, and fix-loop McLoop setup are built by reusable helper functions.
  - Existing Vroom CLI, daemon, triage, auditor pool, and YOLO tests still pass.
  - The public `bob vroom`, `bob vroom now`, and `bob vroom stop` command behavior remains unchanged.
- description: Extract Vroom construction from `claude_orchestrator/bob/cli.py` into focused config and app wiring helpers while preserving current command behavior.
